# مساري | MASARI

مساعد دراسي مفتوح المصدر لكل الطلاب والمراحل. ملف واحد (`index.html`) بلا خادم ولا حساب، وبيانات الطالب تبقى في متصفحه فقط.

## التشغيل
- محليًا: افتح `index.html` في المتصفح.
- نشر مجاني: ارفع هذا المجلد إلى GitHub Pages أو Netlify أو Cloudflare Pages.
- التثبيت كتطبيق (PWA): يلزم تقديم الملفات عبر HTTPS (الملفات `manifest.webmanifest` و`sw.js` و`icon.svg` جاهزة). لم تُختبر شروط التثبيت في كل المتصفحات، وقد يحتاج Chrome إلى أيقونات PNG بحجم 192 و512.

## الميزات
إعداد الطالب، جداول أسبوعية ومتناوبة، مساعد يومي يقترح الدرس، جلسات مذاكرة بمؤقت وتسجيل الفهم، متابعة الجلسات الفائتة وإعادة الجدولة، دروسي، مكتبة PDF (IndexedDB)، منشئ اختبارات من نص PDF، سجل أخطاء وإعادة اختبارها، مواعيد اختبارات مع خطة مراجعة تلقائية، إحصائيات، نسخ احتياطي JSON.

## حدود معروفة
- الإشعارات تعمل والموقع مفتوح فقط. الإشعارات في الخلفية تحتاج Web Push وخادمًا (مفاتيح VAPID) وهو غير موجود.
- توليد الأسئلة قائم على قواعد داخل المتصفح بدون ذكاء اصطناعي، ويستخدم نص الملف فقط. لا يوجد OCR للملفات الممسوحة.
- النسخة الاحتياطية لا تتضمن الملفات المرفوعة.
- لا حسابات ولا مزامنة بين الأجهزة، ولا صلاحيات معلمين أو أولياء أمور بعد.
- لا توجد مفاتيح API أو أسرار في الكود. أي تكامل مستقبلي مع نموذج ذكاء اصطناعي يجب أن يمر عبر خادم وسيط يحفظ المفتاح.
